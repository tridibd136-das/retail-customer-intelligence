# Retail Customer Intelligence & Sales Analytics

## Project Overview

This project analyzes retail sales data using Python.

### Features
- Data Cleaning
- Exploratory Data Analysis
- Customer Segmentation (K-Means)
- RFM Analysis
- Sales Forecasting
- Business Recommendations

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Google Colab

### Dataset
Retail Sales Dataset from Kaggle
